# Contributing to Socio Studios

We are preparing the source projects for public collaboration. For now, issues
in this repository are appropriate for documentation corrections, questions about
the roadmap, and proposals for reproducible conversation-analysis experiments.

For a useful report, include the component, expected behavior, observed behavior,
software version when available, and a minimal synthetic or licensed example.
Separate recognition errors, speaker errors, network delay and interpretation.

Do not upload private conversations, credentials, pairing tokens, signing keys,
or identifying voice samples without appropriate permission. Remove personal
information from logs. Do not post security-sensitive details in a public issue;
a private reporting channel will be documented before a supported public release.

Games and media proposals should describe the intended experience and a small
demonstration. No contribution should require replacing the hub's canonical
speaker/transcript ledger with client-side guesses.

Licensing will be specified per project before source release. This repository
does not grant a blanket license to unpublished code or third-party datasets.
